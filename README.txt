CONTROL DE CAPITAL — primera versión funcional

Archivos:
- index.html: aplicación.
- manifest.json: configuración para instalar como app web.
- sw.js: soporte básico de funcionamiento sin conexión después de la primera carga.

Publicación:
1. Sube los tres archivos a la raíz del repositorio GitHub Pages.
2. Activa GitHub Pages desde Settings > Pages si todavía no está activo.
3. Abre la URL publicada desde Safari en iPhone.
4. Usa Compartir > Añadir a pantalla de inicio.

Datos:
- Se guardan en localStorage del navegador/dispositivo.
- No hay sincronización en la nube.
- Exporta copias JSON desde Configuración periódicamente.
- No borres los datos de Safari si quieres conservar los registros.

Nota:
Esta es una primera versión funcional. Antes de usarla como registro financiero definitivo,
prueba los cálculos y conserva copias de seguridad frecuentes.
